Сборник скриптов и утилит для разных задач. 

# Дерево репозитория

1. ***PixelGridApp*** - Программа с графическим интерфейсом (GUI) на Python, разработанная для точного наложения координатной сетки на изображение, масштабирования с пиксельной точностью и последующей «подгонки» (пикселизации) картинки под настроенную сетку. Подходит для создания схем вышивки, мозаики, пиксель-арта или анализа текстур.
